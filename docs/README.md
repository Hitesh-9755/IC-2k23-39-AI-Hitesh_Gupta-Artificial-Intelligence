# Documentation

This folder contains supplementary documentation for the AI Laboratory
repository.

## Contents

| Folder / File | Description |
|---------------|-------------|
| `algorithm-flowcharts/` | Flowcharts for search algorithms, rule engines, etc. |
| `architecture-diagrams/` | System architecture diagrams for mini project |
| `performance-analysis.pdf` | Consolidated performance analysis report |
| `mini-project-report.pdf` | Mini project report (XAI Dashboard) |

## Adding Diagrams

Place `.png`, `.svg`, or `.pdf` files in the appropriate subfolder.
Flowcharts can be created using tools like draw.io, Mermaid, or LaTeX
tikz.
