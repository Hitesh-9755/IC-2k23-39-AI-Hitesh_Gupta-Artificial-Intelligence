This repository contains the complete set of AI laboratory assignments covering problem formulation, search algorithms, data preprocessing, knowledge representation, machine learning, deep learning, and explainable AI.

## Repository Layout

| Folder | Contents |
|--------|----------|
| `Lab1/` | Production rule systems, Water Jug, Missionaries & Cannibals, Vacuum Cleaner, rule-based applications |
| `Lab2/` | BFS, DFS, Hill Climbing, Best-First, A* search; maze and 8-puzzle solvers |
| `Lab3/` | Data preprocessing and EDA on `placement.csv` and `iris.csv` |
| `Lab4/` | Knowledge representation: predicates, semantic networks, frames, rule engine |
| `Lab5/` | Decision Tree classifier with evaluation metrics and visualizations |
| `Lab6/` | PyTorch fundamentals: tensors, autograd, linear regression training loop |
| `Lab7/` | Grad-CAM, FGSM adversarial attacks, PCA/SVD, mini project |
| `datasets/` | CSV datasets used across labs |
| `models/` | Trained model artifacts (`decision_tree.pkl`, `linear_regression.pt`) |
| `docs/` | Flowcharts, architecture diagrams, and report PDFs |
